# Codveda Level 1 Task 2 — Interactive Form

Responsive sign-up form built with semantic HTML, CSS, and vanilla JavaScript.

## Features
- Name, email, phone, and password fields
- Real-time validation and inline error messages
- `input`, `blur`, and `change` event handling
- Password strength indicator and show/hide control
- Terms checkbox validation
- Success message without page reload
- Responsive layout and accessible labels

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Note
This is a frontend demo. It does not submit, store, or transmit form data.
